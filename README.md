# Changes Made

# Problem

Failures in previous sprint was that the page was not organzied and the content of the site was stacked on top of eachother once the html code was modernized.

# Solution

Started coding in the css file to help with the organziation and flow for
the reader. Added grid layout displays to keep the contents/sections
organzied in the appropiate sections.

# Why

The choice is appropiate because having the contents organzied in their
respective section helps keep the user have better eye flow for the page.
The navigation bar reads from left to right in order and the page itself
reads in order from top to bottom, which corresponds with the navigation.

I'd say that my biggest use of the grid section was in my .contentSection
of the page. The use of it really helped with the way it organzied the
page layout. At first it weirded me out becuase it looked really clunky at first,
though once I added a few div blocks in the code it really helped with the way how the page looked.
